# ⚡ TaskFlow — Todo Application

It provides a seamless user experience for managing tasks, and perform all crud operations.

## ✨ Features

- **🛡️ Secure Authentication**:
  - Email & Password registration with input validation and password hashing.
  - JWT (JSON Web Tokens) session persistence.
  - Google OAuth / JWT integration powered by Supabase.
- **📊 Real-time Analytics**: Interactive statistics cards calculating overall progress, active tasks, high priority alerts, and completion rates.
- **🔍 Advanced Query Filters**:
  - Filter tasks by sidebar sections (All, Today, High Priority, Completed).
  - Filter tasks by status tab (All, Active, Completed).
  - Instant text-search filter
